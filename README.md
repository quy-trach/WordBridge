# 📖 WordBridge

**WordBridge** is a modern and lightweight translation application that helps users quickly look up and understand words or short phrases between multiple languages.  
It’s built to be fast, clean, and intuitive — making language learning and cross-language communication easier than ever.

---

## ✨ Features
- 🌐 **Instant Translation** – Get word meanings instantly between supported languages.  
- 📚 **Detailed Dictionary** – Includes definitions, example sentences, and alternative meanings.  
- 🕘 **Search History** – Automatically saves your recent translations for quick access.  
- 🎨 **Minimalist UI** – Distraction-free interface focused on usability.  
- ⚡ **Fast & Lightweight** – Runs smoothly on most devices without heavy resource usage.
